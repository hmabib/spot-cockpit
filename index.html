Validation → Documents → Note → Douane → Facture douane → BAE → Mise en livraison → Retour → Facture intervention → Validation finale → Archivage. Les paires incomplètes ne sont pas estimées et les inversions sont exclues des statistiques. Qualité des données (% du périmètre) : vert = séquences terminées · orange = en attente · rouge = inversions exclues · bleu = clôturées sans cette étape · violet = départ futur · gris = date de départ non saisie. ETA est une prévision, RTA l’arrivée réelle : leur écart peut être négatif (avance) et reste distinct du traitement documentaire, qui peut commencer avant l’arrivée.
